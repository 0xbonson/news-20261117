## Overview

This repository contains an entry for the [make.fun news-image competition](https://make.fun/bounty/news-image-20261117).

This entry was produced by an AI coding agent for make.fun's news-image competition. The shipped picture is the work of the entrant and is not modified by the program.

## Running Locally

To execute the packaging script locally:

